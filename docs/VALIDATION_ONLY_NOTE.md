# Interpretation of validation-only post-hoc tables

Files containing `VALIDATION_ONLY` are **not test estimates** and must never be merged into the Table 3/4 test report. They document the behavior of the predefined tolerance selector on candidate validation scores. The exploratory DC tuning experiment also selects C from validation only, and reports selected-model test results separately. The only primary confirmatory testing family remains the 12 paired component tests described in the revised manuscript.
