# Code license decision

The repository is not assigned an open-source license automatically by this package. The copyright holders/coauthors should agree on a software license before public release (e.g. MIT if all coauthors authorize it). Third-party datasets, pretrained weights and images have separate terms and must not be covered by the code license. A public repository without a license is viewable, but third parties do not automatically have permission to copy or redistribute the code.
